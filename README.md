# Flash Cards

Elementary math flash cards for Android. What the app does is in [PLAN.md](PLAN.md). How to install it on a phone is in [ANDROID_SETUP.md](ANDROID_SETUP.md).

Build the debug APK and run the unit tests from this folder:

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest
```

The debug APK is written to `app/build/outputs/apk/debug/app-debug.apk`.
